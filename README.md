# Leo System

## Summary
A web-based system designed to streamline and manage institutional workflows, user authentication, and core administrative services.

## Current stack
- Client: Flutter Web / Dart[cite: 2, 7]
- Planned Backend: REST API (e.g., FastAPI)[cite: 2, 7]
- Persistent Storage: PostgreSQL[cite: 2, 7]

## Run locally
Clone this repository and run the following commands in your terminal:

flutter pub get
flutter run -d chrome
